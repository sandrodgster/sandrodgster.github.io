Visão geral

O Projeto Orion nasceu com o objetivo de criar um portfólio profissional que apresentasse projetos de design, comunicação visual e desenvolvimento web em uma interface clara, acessível e responsiva.

O desafio

O principal desafio foi organizar diferentes áreas de atuação em uma única página, mantendo uma comunicação simples, boa hierarquia visual e funcionamento adequado em diferentes tamanhos de tela.

Soluções desenvolvidas

  • Estrutura HTML semântica.
  • Layout responsivo com Flexbox e CSS Grid.
  • Menu mobile acessível com JavaScript.
  • Ano automático no Footer.
  • Cards para habilidades e projetos.
  • Imagens com tratamento de enquadramento.
  • Navegação por teclado com foco visível.
  • Suporte à redução de movimentos.

Interface e responsividade

Projeto em diferentes telas

A interface foi desenvolvida para manter clareza, organização e consistência visual em computadores, tablets e celulares.

Principais aprendizados

Durante o desenvolvimento, pratiquei organização semântica, responsividade, manipulação do DOM, acessibilidade, versionamento de código, resolução de conflitos e publicação de páginas estáticas.
